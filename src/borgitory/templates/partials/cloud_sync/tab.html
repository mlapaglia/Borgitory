Cloud Sync Configuration

Cloud sync mirrors your local repository files with rclone. If the local repository is corrupted or encrypted by ransomware, the next sync copies the damage to the cloud and overwrites the healthy copy. For an independent off-site backup, create a separate remote repository on a borg server (for example ssh://user@host/./repo) and back up to it directly.
